Listen auf ein anderes Gerät mitnehmen

Brauchst du das?

Der Trainer funktioniert ohne Anmeldung. Deshalb speichert er deine eigenen Listen, deinen Lernstand und deine Flammen nur hier: in diesem Browser auf diesem Gerät. Wenn du immer mit demselben Handy übst, musst du nichts tun.

Mitnehmen lohnt sich, wenn du ein neues Handy bekommst, auf einem zweiten Gerät üben willst oder den Browserverlauf löschst. Die Listen deiner Lehrkraft sind auf jedem Gerät von selbst da.

Weg 1: QR-Code abfotografieren

Öffne den Trainer auf dem anderen Gerät, tippe unten auf „Gesicherte Listen laden“ und dann auf „QR-Code fotografieren“. Fotografiere damit diesen Code.

Weg 2: Code kopieren

Kopiere den Code und leg ihn in deinen Notizen ab oder schick ihn dir selbst. Auf dem anderen Gerät fügst du ihn unter „Gesicherte Listen laden“ ein.

Code anzeigen

Gesicherte Listen laden

Hol deine Listen von einem anderen Gerät hierher. Was hier schon gespeichert ist, bleibt erhalten.

Den QR-Code zeigt dein anderes Gerät unter „Listen mitnehmen“.

oder Code einfügen

So funktioniert der Vokabeltrainer

  • Fotografieren: Sprache wählen, Vokabelseite gerade von oben fotografieren, kurz prüfen, speichern.
  • Üben: Karteikarten, Auswahl aus vier Antworten oder selbst schreiben.
  • Wackelkandidaten: Die Punkte unter einem Wort zeigen, wie sicher du es kannst. Falsche Wörter kannst du gezielt wiederholen.
  • Ohne Konto: Fotos werden auf dem Gerät gelesen und nicht hochgeladen. Alles wird nur in diesem Browser gespeichert.
